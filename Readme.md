# پروژه رادار نفوذگر به زمین (GPR) هوشمند با پردازنده STM32F4

## معرفی پروژه
این پروژه یک سیستم کامل GPR مبتنی بر تکنولوژی SFCW (موج مداوم فرکانس جاروب‌شده) است که با هدف کاوش عمیق (تا عمق ۱۰ الی ۲۰ متر) و رزولوشن بالا طراحی شده است.

### ویژگی‌های کلیدی:
1. **معماری اقتصادی و هوشمند:** تقسیم کار بین Rover (به عنوان هاب سنسورها با STM32F4) و گوشی هوشمند (برای پردازش IFFT, SLAM, AI, AR).
2. **فرکانس جاروب گسترده:** بازه ۳۵ مگاهرتز تا ۴۴۰۰ مگاهرتز با ماژول ADF4351 جهت نفوذ عمیق و رزولوشن بالا.
3. **موقعیت‌یابی مستقل از GPS:** استفاده از ماژول‌های UWB (DWM1000) و IMU (BNO085) با الگوریتم EKF SLAM.
4. **رابط کاربری چندزبانه:** پشتیبانی از ۶ زبان (فارسی به عنوان پیش‌فرض، انگلیسی، عربی، ترکی، فرانسوی، اسپانیایی).
5. **واقعیت افزوده (AR):** نمایش لایه‌های زیرزمینی روی تصویر زنده دوربین گوشی.

---
توسعه یافته بر اساس استانداردهای مهندسی الکترونیک و پردازش سیگنال.
